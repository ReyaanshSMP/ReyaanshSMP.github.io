What is an SMP?

Survival Multiplayer

SMP stands for Survival Multiplayer. Players share a Minecraft world, gather resources, build structures and explore together. Your adventure is what you make of it.

Connection instructions
1

Open Minecraft Java Edition

Start Minecraft Java Edition on your computer.

2

Open Multiplayer

Choose the Multiplayer option from the main menu.

3

Add a server

Choose Add Server and enter ReyaanshSMP as the server name.

4

Enter the server address

Paste the address shown above into the Server Address field.

5

Join the server

Save the entry, select ReyaanshSMP and click Join Server.

Community guidelines

Server rules

Basic guidelines for keeping the server enjoyable for everyone.

handshake

Respect other players

Be respectful. Harassment, bullying and targeted abuse are not acceptable.

security

Play fairly

Do not use unfair advantages or tools that disrupt normal gameplay.

forum

Keep chat appropriate

Avoid spam, excessive disruption and inappropriate messages.

landscape

Respect other builds

Do not damage or take other players' creations and belongings.

admin_panel_settings

Follow staff instructions

Cooperate with server staff when they are handling an issue.
